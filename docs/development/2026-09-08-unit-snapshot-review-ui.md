# 私有条件快照入口

后台可从当前已完成规则终局裁决的目标整理条件快照并打开专用查看页。POST / GET 都调用受信快照服务；不会在详情接口直接返回未经重建的缓存 JSON。成功及业务错误均标记 private/no-store，未启用环境隐藏入口；过期事实、校验器、版本或无效关联拒绝读取，页面明确提示返回任务处理。

页面以浏览器为主，保留公告/本组/本目标条件、原始备注和引用、未知/未定位/拒绝等状态、全调查证据三态、排除的别岗/别组字段及实际独立批准记录。源行展示必须匹配当前 FactPreparation、RulePreparation、EvidenceCheck、绑定和 ACTIVE 事实集；不从历史摘要猜测当前内容。有效期终点未确定照实显示。完整适用范围与例外仍待审核，未接个人画像或资格结论，公开页面不变。
