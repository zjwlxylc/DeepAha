# 岗位条件范围预检

本批提供私有只读接口 `GET /api/v1/local-human-test/investigations/{task_id}/unit-plans/{plan_id}/scope-preflight`，为完整范围和时间边界审核提供缺口清单。它是诊断入口，不是完整范围签署或资格放行。

## 当前行为

- 从当前数据库重建公告、组级和岗位条件，返回完整条件分母、其他目标排除行、原始备注和未核验证据引用。缺行、重复行或总数不一致不能生成预检结果。这里的分母是已登记来源行，不代表所有官方原件已发现。
- 返回各条件的适用状态，以及同字段、跨层活动条件对尚未被当前批准关系覆盖的清单。只统计审阅覆盖，不执行累计、替代或例外；不同字段之间的潜在条件关系仍需独立范围审核。
- 所有关系在同一事务内重读完整裁决历史；过期、拒绝、待裁决及未审阅关系不能计入当前批准覆盖。已批准冲突仍阻塞，任何交叠的批准关系保守地列入共同审核候选，不自行选择胜出者。
- 基于服务器时钟报告已有岗位证据的未生效、过期、记录区间内及结束时间未建立四种状态。区间为开始包含、结束不包含；空结束时间不能证明无限期有效。复用现有受限内核输出 `local_kernel_blockers`，该字段只描述原生岗位计划，不将它当作完成继承后的执行结果。
- 组级/公告继承尚无已批准有效期契约，因此显式保留继承时间边界缺口。所有既有上游阻塞、完整范围未核验及 `UNCERTAIN / executable=false` 保留。
- 继续要求合适角色、用途和当前有效账号；禁止模拟身份通过真人审核入口。输出及错误采用 `private, no-store`。任务锁与返回前来源/权限复核沿用关系审阅流程，不写审核事件或修改批准记录。
- 为避免分页前半部分被误当完整范围，单岗位超过 200 条关系提案时返回 `409 SCOPE_PREFLIGHT_RELATION_LIMIT`，不输出截断后的“完整”结果。

## 验收与边界

先验证模块缺失、接口 404 和三种分母遗漏样本失败，再实现。定向回归见 [单元与资格内核证据](evidence/2026-09-11-scope-preflight-unit.xml)及[数据库与 API 证据](evidence/2026-09-11-scope-preflight-integration.xml)；最终集成以本批候选 CI 为准。测试均为合成材料和账号，不是真人批准。

本批不增加迁移、写入接口或页面。下一切片将把预检接入私有审阅页面；随后独立实现完整范围/有效期的证据绑定与追加审核契约，再讨论例外执行和解除具体限制。Word UNVERIFIED、原件发现完整性及真实发布资格保持各自的证据责任。
