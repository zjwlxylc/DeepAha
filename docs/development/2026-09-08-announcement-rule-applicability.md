# 公告规则对指定岗位的独立适用性审阅

本批把一条已批准公告规则与一个当前岗位条件快照连接到单独的适用性审阅记录。审核人员可明确选择适用、排除或待裁决，并保留理由、具体材料原件、字面引文、结构位置及前后决定历史。记录不会修改已有快照或当前资格计算结果；整体仍为 UNCERTAIN。

来源公告与目标岗位须来自同一当前调查、身份绑定、事实准备及官方来源包。每次读取、保存和相同请求重试均重建核对原件、共同证据检查、实际事实与规则批准、机会和岗位版本；当前权限被撤销后返回 403。读取或分页失效时隐藏旧数据，不把历史回执作为当前准入。适用和排除均要求当前原文中的字面片段，机器只核验出处，语义决定属于独立审核人员。
