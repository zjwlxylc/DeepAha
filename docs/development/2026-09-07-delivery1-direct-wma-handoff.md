## 已实现的行为

- 从当前数据库中已经启用、允许存储的一手官方来源登记明确公告和调查说明，附可选材料/子项清单、校准标识及 60–1800 秒上限。登记不会调用外部服务。最小来源输入继续使用现有 `deepaha.sources.cli import-registry`；完整来源导入工具适配留在交付三。
- 冻结任务请求、来源策略、SOP、两份原始 Schema、提示构造器与 SDK 0.3.4 的摘要。真正执行由本地运营身份显式启动，单任务只发起一次调查 prompt；预置任何文件失败即停止。
- 从供应商只读接口精确解析公开标识、数字 Agent ID、发布版本、提示词摘要、模型配置和技能摘要；创建发布会话后再次检查配置。Runtime 和 Session 分步持久化，后一阶段失败时保留已取得的标识。调查前发现发布变化或配置不符不会发送 prompt；恢复只取原运行文件，不跟随新版本重新调查。
- 任务输入提供启动后剩余时间、绝对截止、建议交付时间及既有文件/大小/解析上限。回收预留是对 Agent 的行为要求，执行器强制的是整轮绝对截止，不声称云端网络或货币费用有硬上限。
- 三件套及所有登记原件必须回收。原件始终保留字节，不经过字符串转换。下载只发生在该任务的固定沙箱目录；文件、大小和解压量有上限。
- 重新计算 SHA-256，核验实体树、嵌套/扁平事实、支持格式的引文与定位。空事实、漏原件、错误清单、跨任务结果、超出来源范围、材料或子项清单不完整均不能进入待审。
- 实际字节通过现有 RawArtifact / ObjectStore 保存。HTTP 状态未知则留空；来源 URL 明示为调查方声明，不伪造静态采集或 Fetch。P9B 既有正式事实与资格体系保持原有权威。
- PostgreSQL 保存任务、材料关联和状态事件。请求与冻结交付不可覆盖；同请求回执丢失可查询/幂等返回。回收失败后可恢复原 Runtime/Session，只取文件、不再次调查；已冻结三件套在恢复时发生变化会拒绝。
- 原件通过受保护的下载接口提供，保留经过白名单验证的安全扩展名。仅具有对应用途及角色的非合成真人账号可以提交内部审核；审核绑定交付摘要，并在提交前复核自有存储字节。

内部 `APPROVED` 仅表示该批摄取材料已被真人记录为审核通过，不自动生成公开目录、资格规则或正式 VerifiedFactSet。批准事实到 Opportunity / Unit / 规则的桥接属于既定路线的交付二。未知或不支持格式继续保留疑点，不由机械检查代替语义裁定。

| 配置 | 用途 |
|---|---|
| `DEEPAHA_WMA_LIVE_ENABLED` | 显式启用真实连接 |
| `DEEPAHA_WMA_API_KEY` | WMA 密钥，仅在当前进程使用 |
| `DEEPAHA_WMA_AGENT_ID` / `DEEPAHA_WMA_SOURCE_APP` | 已核对的调查 Agent 与调用方 |
| `DEEPAHA_WMA_MANIFEST_VERSION` | SDK manifestVersion，默认 `1.0`，不是已发布业务 Agent 版本 |
| `DEEPAHA_WMA_REVIEWER_TOKEN` | 已授权本地运营会话，不能使用合成运营账号执行 live |

密钥与会话不要写进命令参数、Git 或交付报告。`preflight` 只输出是否配置，不输出值，也不访问 WMA。

配置 WMA 后可先执行 `inspect-agent`：只读核对发布记录，不创建 Runtime、不访问业务数据库、不发送调查。下列运行与回收命令仍要求有效本地运营身份和调用授权；`--agent-release-reference` 仅是可选人工备注，不能替代供应商读回证据：

```powershell
uv run --extra wma python -m deepaha.investigations.cli inspect-agent

uv run --extra wma python -m deepaha.investigations.cli run <task_id> `
  --authorization-reference <本次调用授权记录>

uv run --extra wma python -m deepaha.investigations.cli show <task_id>

uv run --extra wma python -m deepaha.investigations.cli recover <task_id> `
  --authorization-reference <本次回收授权记录>
```

恢复单次最多 120 秒，需等待原租约到期；不会再发 prompt。Runtime 创建本身失去回执且无可用远端 ID 时，系统保持执行不确定，需要运营从服务端定位，本批不声称可以自动找回未知 Runtime。预置失败的任务不能自动重跑调查。

当前输入契约为 `direct-wma-intake/2`。旧契约登记且未执行的任务不能静默改用新版输入，应重新登记；已经开始的旧任务仍可按原记录回收。会话提示词由供应商脱敏为 `***` 时记录 `MASKED_BY_PROVIDER` 和 `prompt_hash_verified=false`，不能把脱敏值当缺失，也不能声称比对过会话中的提示词全文。模型证据是配置，不是实际生成遥测。
