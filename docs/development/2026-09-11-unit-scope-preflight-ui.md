# 条件范围预检私有页面

新增 `/review/investigations/{task}/unit-plans/{plan}/scope-preflight`，从岗位快照和跨层条件总览进入。页面读取 PR #49 的只读接口，展示全部登记条件、来源和备注缺口、关系审阅状态、未覆盖/交叠条件关系，以及岗位证据时间边界。条件原文、岗位规则、任务原件和关系详情均有对应入口。

显示时间统一为北京时间。空有效期结束时间明确为尚未建立，不表示永久有效；空条件、空关系或空时间记录均不显示为验证通过。完整范围与继承时间边界继续保留阻塞，页面不写审核记录或放行资格。

服务器端使用现有审核会话和 `no-store` 读取。接收时核对任务/岗位、版本、条件分母、唯一身份、关系状态与引用、时间区间和状态一致性，以及只读/不确定标记。读取前隐藏旧结果，失败后提供重试；页面切换使用任务/岗位和初始结果作为实例键。读取 401/403/404/409/500 或无效结果时均不展示旧批准状态。

## 验证

- 数据样本由实际合成 PostgreSQL/API 测试导出，保留当前与来源变更后两份结果；不使用真人或真实资格批准。
- [27 项定向 Web 回归](evidence/2026-09-11-scope-ui-unit.xml)通过，涵盖结果校验、加载时隐藏、错误恢复、空状态及既有总览/队列兼容。
- 5 项 Chromium 浏览器回归通过；按钮间距调整后重新运行新增桌面 1440px、手机 390px 两项场景，均通过。覆盖键盘操作、旧来源失效、权限失败与恢复、无横向溢出。
- TypeScript、ESLint 和生产构建通过，新路由按请求动态渲染。候选完整 CI 结果见本批 PR。
- 视觉检查：[桌面](evidence/2026-09-11-scope-ui-desktop.png)、[手机](evidence/2026-09-11-scope-ui-mobile.png)。截图来自开发服务器，角落开发指示器不属于生产页面。

本地最初的浏览器运行中，旧开发缓存导致既有路由也返回 404；隔离该缓存后恢复，未改变生产路由策略。浏览器错误断言限定到页面自身提示，避免误选框架空的路由通知区。

下一步是完整条件范围与时间边界的证据绑定、独立追加审核契约；本页和预检 API 本身不是该审核的批准凭证。
