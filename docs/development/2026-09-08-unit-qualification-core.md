# 精确岗位资格的受限离线核心

本批新增纯离线契约、规则编译与资格评估，只接受 `unit-qualification/2.0.0` 及对应覆盖策略。参考未合并分支 4608d5b 的安全策略，拒绝旧 1.0/1.1/1.4 输入，不迁入历史兼容通路或治理表。当前业务 API 和页面尚未调用该核心。

输入精确绑定 Opportunity ID/版本及 Unit ID/版本号/UnitVersion UUID，保留完整来源条件、原始行摘要、UNKNOWN / UNPROCESSED / CONFLICT / UNSUPPORTED 等状态、规则准入和所有证据的有效期。输入一致性检查不代表审批身份已认证或官方材料已完整调查；后续受信适配器必须从当前数据库与不可变证据链加载并验证。

当前没有完整范围及例外的可信审核接线，所有计划保留 `HUMAN_SCOPE_REVIEW_UNVERIFIED`。`status` 始终为 `UNCERTAIN`，`engine_status` 只表示可执行根图的局部结果。有效叶子的独立诊断由 `diagnostic_rule_ids` 明示，不参与根结论或取代失效的 AND/OR 操作数。未填写信息不能通过 `NOT_EXISTS` 被当作明确不存在。

证据有效期按左闭右开计算，过滤后重新计算权威优先级、冲突和每项绑定条件的证据覆盖。规则和输入摘要包含完整计划、画像内容、专业目录及批准映射的实际内容、两个时钟、规则图/单元编译器/引擎/契约版本，以及独立诊断的当前证据。
