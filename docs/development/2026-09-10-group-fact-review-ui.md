# 单位组字段审核管理页面

状态 IMPLEMENTED，本地定向验证通过，候选 CI 尚待完成。分支 `codex/group-fact-review-ui`，基于 PR #27 同树合并。后端的原件、冻结 Schema、字段事实和规则均未修改。

已登记组来源新增“进入组字段审核”。准备页为 `/review/investigations/{taskId}/group-bindings/{recordId}/facts`；保存后使用固定地址 `/review/investigations/{taskId}/group-facts/{prepId}`。两个页面强制动态读取，GET 不自动写入。桌面原文/证据与审核表单并排，窄屏自然堆叠，原首页及公开页面保持不变。

准备仅提交当前来源摘要和证据回执。独立裁决只提交决定、证据支持、优先级核查与理由，不允许修改候选值。UNKNOWN 不提供批准为已知的选项；未核验/不支持字段继续显示待处理，不提供裁决按钮。全部可审核候选完成终局裁决，且至少一项获批或保留未知后才显示保存入口。保存事实集不宣称组规则、岗位继承或完整资格已批准。

服务器动作核对精确组身份、当前回执、原始字段与完整分母、证据对应和返回记录。成功写入后重读具体记录；没有相符裁决/事实集回执则不报告保存成功。失败时隐藏旧内容，只有回执不可达时保留原请求供明确重试，同一请求使用稳定幂等键；不自动提交或自动刷新旧裁决。

只读复核发现旧任务展示层会补充 `note`，与冻结原始对象不完全相同。已通过失败用例复现并修复：原始事实缺少备注时只忽略展示层新增的该属性；原有备注变化、其他字段变化、错误分母和证据仍拒绝。排除行摘要仅接受展示原样或缺失备注这两种已知表示。原始回执与摘要不被重写。复核未发现剩余 P1/P2。
