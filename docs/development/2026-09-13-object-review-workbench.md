2026-09-13：R1-B 与 R1-C 的工程实现及本地验证完成；本候选远程 CI/合并待取得证据。真人两个岗位闭环仍未完成，Scout v0.3.0 实包尚未取得。工程结果不提升 Release Qualification 或契约成熟度。

## 交付行为

- 已批准任务从队列进入 `/review/investigations/{task_id}/workbench`。显式选择公告、单位或岗位，再选择材料、身份、字段、规则步骤；不自动选择或批准对象。旧详情和历史深链保留。
- 已有归属的整体修订必须进入完整页面选择全部保留项；单对象页不呈现会替换整套归属的旧表单。新增身份入口继续使用保留已有归属的原服务，避免第二个岗位覆盖第一个岗位。
- 服务端按对象及 offset 返回一个字段/规则表单，保留原件、定位、候选与独立决定。2527 条合成候选不会全量传给字段表单。规范化前的完整 JSON 仍需在服务端读取用于现有完整性检查，本次没有把事实存储改成逐行 SQL 表。
- 待处理、未知计数和事实晋升门根据完整对象计算，分页不减少分母。范围、继承、历史和 UnitPlan 继续使用已有完整页面；当前字段完成不表示完整资格。
- 字段/规则未提交草稿仅存当前窗口内存，绑定会话、任务、材料、对象、准备及决定版本；切换对象可恢复并保留请求标识。刷新、关闭、重新登录和身份登记表单不承诺恢复。不写浏览器持久存储。
- 工作台提交先查询当前审核员、任务、准备版本和请求键的持久回执。超时或服务端错误后再次查询，查到则回读成功，不发送第二次写入；查询不可用保持不确定与草稿。401 给出登录失效指引，409 要求重新核对版本。
