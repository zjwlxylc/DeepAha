# SG5 验收标准

SG5 只有同时满足以下条件才可以交给用户人工验收：

1. SG1–SG4 全部产品测试无回归；
2. SG5 新增核心/API 测试通过；
3. `INELIGIBLE` 绝不进入个性星图；`UNCERTAIN` 不被误写为符合；
4. 候选池有界，不能对全部用户×全部机会调用模型；
5. 不调用 WMA/外部 LLM 做本轮排序；
6. 用户可关闭个性化，关闭后机会总览仍正常；
7. Top-N 有 root 多样性；
8. 解释必须包含“为什么值得我关注 / 为什么现在 / 风险”；
9. 不出现伪精确匹配分或成功概率；
10. 时间不确定时不得制造倒计时；
11. 至少一个校准集上 Top-N 优于旧式关键词基线；
12. 用户上传的真实 WMA 数据可以离线回放，验证多类别真实 Target 的排序行为。

最终产品 Gate E 仍需要用户本机人工验收；本包不把工程校准结果冒充真人盲评结论。
