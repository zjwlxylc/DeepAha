# SG5 Windows 本地复现与人工验收

## 0. 原则

- 不覆盖唯一旧程序副本；把 `3.5.0-rc1` 解压到新的代码目录。
- 先备份 `C:\Users\LENOVO\deepaha-data`。
- SG5 **没有数据库 Schema 迁移**，不会因为打开“我的机会星图”重新调用 WMA。
- 不要把项目内虚构 examples 导入正式数据库。

## 1. 启动

1. 停止 SG4 程序。
2. 解压本包。
3. 保留现有 `C:\Users\LENOVO\deepaha-data`。
4. 双击根目录 `启动机会星图.cmd`。
5. 登录原账号。

先打开“机会总览”，确认 SG1–SG4 已验收的数据仍然存在。

## 2. 验收 A：现有画像“宁波 + 政策”

如果你的本地数据与本轮上传快照一致，当前有 328 个 Catalog Target，其中 300 个招聘岗位、21 个竞赛赛道、7 个政策分项。

进入“我的 → 我的关注方向”：

- 城市：宁波；
- 兴趣：政策；
- **先不要勾选机会类型**；
- 启用个性化机会排序。

打开“我的机会星图”。

预期：

- 标题为“今天真正值得你看的”；
- 真正的 `YOUTH_POLICY_BENEFIT` 政策/补贴分项应优先于仅正文包含“政策”二字的招聘岗位；
- 不显示成功率/匹配百分比；
- 时间没有可靠证据时显示“时间节点尚未明确”，不出现虚构倒计时。

本轮上传快照离线回放中，Top 7 均为宁波一次性求职补贴的真实政策分项。

## 3. 验收 B：显式人才政策

在“优先关注的机会类型”勾选“人才政策”，城市=宁波。

预期：上传快照中候选收敛到 7 个政策分项；显式类型选择是强偏好。

## 4. 验收 C：AI 竞赛

修改画像：

- 机会类型：竞赛；
- 兴趣：AI；
- 当前目标：积累项目经历；
- 发展方向：AI产品/技术；
- 地区偏好：地区只是参考。

预期：上传快照中候选为 21 个竞赛赛道，星图应优先展示实际赛题，而不是招聘岗位。

## 5. 验收 D：解释

在星图卡片或具体机会详情点击“为什么值得我关注”。

检查：

- 为什么值得我关注；
- 为什么现在；
- 需要注意；
- SG4 资格状态；
- 不出现“92%匹配度”“成功率”等伪精确数字；
- 页面明确说明排序在 DeepAha 本地完成，不向 WMA/外部模型发送画像。

## 6. 验收 E：关闭个性化

取消“启用个性化机会排序”。

预期：

- “我的机会星图”停止给出个性化 Top-N；
- 明确显示由用户关闭；
- “机会总览”仍然正常浏览和搜索；
- 收藏/行动/SG4 资格页面不受影响。

## 7. 验收 F：SG4 硬资格仍然优先

如果某个 Target 在 SG4 当前证据下明确为 `INELIGIBLE`，它不得出现在 SG5 个性星图中。`UNCERTAIN` 可以保留，但必须显示风险，不能包装成“符合”。

## 8. 反馈

人工验收时建议记录三件事：

1. Top 3 是否确实比普通关键词搜索更值得看；
2. “为什么值得我关注 / 为什么现在”是否符合直觉；
3. 有没有“明明完全不适合，却排得很靠前”的反例。

这三类反馈是进入 SG6 前最重要的真人证据。
