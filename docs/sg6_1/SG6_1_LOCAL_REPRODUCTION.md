# DeepAha SG6.1 本地复现与人工验收

版本：**3.6.1-rc1 / SG6.1**

本版本只做桌面导航、角色入口和三轮 UI/UX 收口；**不新增数据库迁移，也不会重新调用 WMA。**

## 1. 使用现有数据

继续使用：

`C:\Users\LENOVO\deepaha-data`

建议把新的源码 ZIP 解压到一个新程序目录，不要覆盖你唯一的 SG6 程序副本。

然后双击：

`启动机会星图.cmd`

打开：

`http://127.0.0.1:8000`

## 2. 第一轮验收：桌面用户端

登录 owner 或普通 user 后依次检查：

- 顶部是否有：`发现 / 机会总览 / 我的机会星图 / 收藏与行动`；
- 右侧是否有：`消息 / 我的`；
- 我的机会星图是否显示行动摘要；
- 点击 `收藏与行动` 是否可以正常进入 `/app/actions`；
- 收藏、准备、申请、时间线等 SG6 数据是否仍然存在。

SG6.1 的核心修复是：**收藏与行动不再是手机端才容易找到的入口。**

## 3. 第二轮验收：角色入口

当前 `owner` 是用户名，不是角色。默认 owner 同时具有：

`user + reviewer + operator`

所以 owner 应显示 `工作台`，进入后同时看到：

- 内容审核；
- 系统管理。

如果你创建单角色测试账号：

- reviewer-only：用户端应显示 `审核工作台`；进入后只看到内容审核；
- operator-only：用户端应显示 `系统管理`；进入后只看到系统管理；
- user-only：不应显示工作台入口。

后端权限仍然保持 SG6 原有隔离；本版本没有新增 owner 角色或复杂 RBAC。

## 4. 第三轮验收：视觉、表单、响应式与可访问性

建议检查：

- 电脑 1440px/1920px 下主内容不会过分拉伸；
- 1024px 左右仍能正常导航；
- 手机 390px 下继续使用底部 `发现/总览/星图/行动/我的`；
- 表单必填项提交失败时是否在字段附近出现错误文字，而不只是浏览器弹窗；
- 异步按钮是否有 loading/disabled 反馈；
- Tab 键导航时焦点轮廓清晰；
- Windows 开启“减少动画”后，界面不再有不必要位移动画；
- 长机会名称、长机构名、Evidence、后台表格不会让整个页面横向滚动。

## 6. 本轮不验收的内容

SG6.1 没有实现 SG7、支付、复杂账号权限管理后台或新的 WMA 能力。SG1–SG6 的业务结果不应因为本次 UI 调整发生变化。
