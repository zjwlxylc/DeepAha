# DeepAha 机会星图｜全模块体验改善设计基线

审核快照：zjwlxylc/DeepAha，main `84353c7e5286e276d24af8e0342d4d3441c30ec5`；仓库记录的应用发布 `9149e03f00aab99137b6240ac0817f1216213263`。日期：2026-09-20。

## 目标与范围
以当前 SG8-A / Beta Access 已有业务为基础，设计可交给 Codex 参考的完整 HTML 交互复刻版，而不是替换生产程序。用户端降低发现、判断、行动的成本；审核端一次整体决定；维护端让异常与下一步操作清楚可见。保持蓝橙品牌方向、公开机会免费、资格与推荐分离、证据可追溯、合成实验与真实数据隔离。

不进行主线写入、部署、数据库迁移、真实外部模型调用、真实账号或支付操作。页面数据全部是固定的合成案例。浏览器本地模拟状态与生产 API 完全隔离。

## 选择的方案
不采用全量重写，也不采用只换配色。选择“保留业务服务及现有路由，重新组织界面与少量补充查询契约”。用户端保留现有首页、总览、星图、行动、我的；后台以内容生产、系统运行、质量与账号分组。现有原生 JS 可以渐进拆分，不要求迁移 React / Next.js。

## 交互边界
1. 首页只保留第一屏与最终品牌收束，不恢复原来的第 2–4 段说明。
2. 资格状态、推荐价值、时间可信度独立呈现；不生成伪精确匹配百分比。
3. 审核仍是每份返回整体通过/不通过。一般备注不阻断；真实硬阻断不能由界面绕过。审核附言是内部记录，不假设自动成为公开备注。
4. 维护员继承审核员，普通审核员不得管理来源、任务、连接或账号。
5. WMA 回收失败只恢复文件，不重发调查；本地取消不承诺远端停止。
6. AGENS 串行是用户指定策略，不当成已经核验的供应商限制。未知能力保守串行；其他连接只有能力验证后才可开启受控并发。
7. 画像现有 PUT 是整份替换。分步表单不得提交残缺对象；接入时必须合并完整数据或增加带版本校验的 PATCH。
8. 用户端支持手机；后台手机只读，危险操作保留桌面入口。弹窗使用原生 dialog；键盘可操作，无仅拖拽操作。
9. 原型支持正常、空、错误、加载、冲突场景；日期固定按 2026-09-20 演示，不冒充实时。
10. 此独立 HTML 的内联脚本仅用于离线预览。生产 CSP 要求拆回现有 /product 静态 JS/CSS，不能直接覆盖生产 index.html。

## 文件职责与验证
- prototype/domain.js：无 DOM 的权限、状态机、并发政策、画像合并、审核保护。
- prototype/fixtures.js：合成案例与初始状态。
- prototype/ui.js：图标、导航、卡片、弹窗、提示和导出。
- prototype/pages-user.js：用户端页面。
- prototype/pages-ops.js：审核、来源、任务、策略、实验、账号页面。
- prototype/app.js：hash 路由、事件和本地持久化；全部动作仅本地。
- prototype/styles.css：统一视觉系统、手机适配及交互状态。
- index.html：以上文件合并后的零依赖单文件。
- tests/domain.test.cjs：业务边界测试。
- tests/browser_qa.py：实际浏览器路由、关键流程、键盘、响应式和无网络访问检查。

验收：关键按钮确实改变本地状态；审核备注/硬阻断有区别；无高风险机会进入重点推荐；移动端无页面级水平溢出；弹窗键盘可关；后退与筛选可复现；源与机会不被混为一层；不存在真实付费或部署调用。
