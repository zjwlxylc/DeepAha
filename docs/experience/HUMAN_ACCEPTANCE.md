## 简短同意说明

“这次体验用于发现页面和流程问题。可以随时停止，不影响正常使用。记录任务能否完成、耗时、误解和自愿提供的原话；不要求上传身份证、完整履历、密码或敏感家庭信息。截图应去除个人资料。参加这次体验不等于同意外发画像或参加机会共创研究。”

## 任务卡

| 角色 | 不提示按钮位置的任务 | 观察点 |
|---|---|---|
| 新用户 | 找一项感兴趣的具体机会，指出官方入口与待确认条件 | 是否把推荐当成资格结论 |
| 已有画像用户 | 只修改一项信息，检查已有城市、证书及通知设置；另一设备同时修改后再保存 | 是否理解冲突，不丢草稿 |
| 用户 | 收藏，添加个人准备事项，刷新，改状态，记录结果 | 是否把个人事项当成官方要求 |
| 用户 | 只看未读，阅读一条与自己有关的变化，当前页批量标记 | 是否误认为已读等于机会无风险 |
| 审核员 | 分别处理有一般备注、硬阻断、版本变化的返回 | 整体决定、409含义，不逐字段审批 |
| 维护员 | 找到第51项以后的来源，从异常源定位具体任务 | 搜索范围/总计是否清楚 |
| 维护员 | 说明“恢复文件”“重新调查”“暂停新调度”的差别 | 是否误触新的收费调用 |
| 手机工作台 | 查看队列、来源与任务，不修改 | 只读原因是否明白，能否继续返回用户端 |

每一行记录一名匿名参与者的一次任务；`human_acceptance.csv` 只有表头，没有填写任何结果。失败、退出和不会操作都如实保留。少量便利样本只能发现问题，不能宣称统计显著。

## 人工放行

重大操作误解、数据丢失、无法返回、难以辨识的关键按钮必须先修复。验收后由负责人填写日期、实际样本、代码标识、问题关闭记录和结论，再批准隔离 staging；是否上线另行明确授权。
