# 跨层级条件组合审核 v1

范围：在已验证的公告范围快照和 GROUP 范围预览之上，建立同一岗位、同一 v2 基础计划的只读组合与离线回放。不是新的资格编译器，不写入审批、事实或规则。

## 契约与边界

- 独立版本 `cross-level-condition-review/1.0.0`。完整保留两个上游输入及其摘要；基础计划必须逐字段相同，不能只比较岗位 ID。输出顺序沿用完整 manifest，一项条件恰有一行。
- 公告和 GROUP 适用结果只统一显示为 INHERITED / EXCLUDED / UNRESOLVED，保留原始投影、决定、证据与历史。UNIT 显示 LOCAL，表示原有岗位层条件，不表示规则可执行或资格满足。
- 仅精确相同 `field_name` 且跨层级的条件进入字段审核组，包含未处理和明确排除项。这是导航索引，不是完整语义冲突检测器；不同字段名也可能有关系。所有关系固定 NOT_EVALUATED。
- 不按层级、数值强弱、文本相似或发布时间自动覆盖。相同字段可能是累积要求、例外、补充或冲突；本版不选择解释。DOES_NOT_APPLY 仅排除该条件对该目标的适用，不批准删除同字段其他条件，也不等价于例外已裁决。
- 原条件的 UNKNOWN / UNPROCESSED / CONFLICT、原规则和 evidence locators 原样保留。组合固定 `executable=false`、`overall_qualification=UNCERTAIN`，保留上游 blockers 并增加跨层级语义未审标记。
- 在线服务在同一事务内重建两个来源，重新授权并再次重建后比较完整输入，拒绝读取期间变化。私有组合函数只消费真实数据库适配器输出，不是客户端提交入口。
- 公开离线回放必须另传在线可信导出时独立保存的 `expected_dependencies_hash`，先计算整个 dependencies 的实际摘要并与之比较，再进入投影校验。禁止把待验包自带摘要当作可信锚。旧公告 `_assemble` 仅生成投影，不能验证审批真实性；本版不把它用作离线审批验证器。完整性与可复现不认证人类身份、不证明当前版本；上线使用必须重新读取真实记录。未知活动 compiler / adapter 仍显式拒绝，摘要正确不等于版本受支持。
- 派生内容按输入重新计算并比较，重新计算外层 hash 不能使删行、修改适用结果或隐藏审核组通过。上游版本未知、基础计划混用及输入不完整均拒绝。

## 实施顺序与验收

1. 本批实现内部只读服务、可回放契约与定向测试；使用合成 PostgreSQL 记录证明三层分母、适用更正、撤权、失效、无写入和 v2 不变。
2. 下一批接入私有只读接口及桌面审核页面；沿用本契约，不增加裁决按钮。
3. 后续才设计明确关系的人工裁决契约、append-only 持久化及执行编译。必须绑定完整输入摘要、精确条件/规则、证据与独立审核人；未裁决关系不得用于硬资格结论。

真实冻结样本不重跑：124 = 94 PASS / 0 FAIL / 30 Word UNVERIFIED；Delivery UNVERIFIED。合成测试不构成真实人工验收或发布资格。
