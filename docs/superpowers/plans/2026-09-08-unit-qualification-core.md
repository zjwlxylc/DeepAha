# 精确岗位资格：受限离线核心

本批先实现无数据库、无网络的岗位资格契约、编译与评估。接在独立规则审核之后，输入来自后续受信适配器加载的真实版本化快照。本批不接 API、页面、画像持久化或审核表，不接受调用者用布尔值或自行填写的回执解锁完整资格。

参考旧分支 `4608d5b` 的安全策略并经独立设计复核，保留未审范围时正负结论均限为 UNCERTAIN。旧 `b56f9b5` 的 1.0 曾允许未审例外时直接否定，不能进入新入口。新核心只接受独立的 2.0.0 契约，不搬入旧版本兼容分支；旧材料和旧分支不改写。

- 精确身份包含 Opportunity ID/版本、Unit ID/版本号及真实 UnitVersion UUID；条件保留原始行摘要、来源层级、未知/冲突/不支持/未处理状态和证据 ID，不能从批准规则反推完整分母。
- 规则准入绑定候选、独立批准、条件、规则摘要及全部证据有效期；校验引用关系仅证明输入一致，不代表数据库认证或来源完整。
- 复用现有 `compile_rule_graph` 与确定性资格引擎；将引擎所需只读规则图字段声明为 Protocol，不制造假 Opportunity、不改历史 RuleSet 语义与哈希。
- 条件未处理、跨范围、无批准、未来批准、失效证据、画像缺失等保留具体原因；缺失子规则会使依赖它的组合不可执行，不丢弃 AND/OR 操作数继续判断。NOT_EXISTS 不能把未填写信息解释为已确认不存在。
- 当前范围与例外没有可信审核接线，所有输入均保留 HUMAN_SCOPE_REVIEW_UNVERIFIED；输出最终状态 UNCERTAIN，同时保留底层 engine_status、逐条冲突、未知与缺失字段。未来解锁需另行实现真实审核回执及完整覆盖验证。
- 回放摘要绑定完整计划、实际画像内容、专业目录与批准映射内容/版本、场景日期与证据时点。证据有效期为左闭右开，过滤失效证据后重新计算有效优先级和冲突。

验收：先移入/编写纯离线失败样本，再实现；覆盖正负限幅、空规则、遗漏条件、跨岗位及版本、证据串用、组合依赖失效、NOT_EXISTS、未来审批、时间边界、优先级和输入摘要。运行相关规则/资格/契约与全部非集成回归、Ruff、mypy 双平台及独立评审；必要 CI 通过后分批合并。纯核心通过不等于实际调查或真人资格验收。
