# 从调查审核记录生成精确岗位快照

接续 PR #18 的受限离线核心。当前批次将数据库中的既有事实与独立规则审核记录转成可重放快照；不接画像或资格结果，不新建范围审批平台，不解锁确定资格。

1. 新建单个不可变 `InvestigationUnitPlan` 快照表及 0042 迁移，用真实 UUID 和实际版本关联 RulePreparation / UnitVersion。只保存派生计划及构造上下文、摘要和操作者，不新增事实或规则批准。
2. 受信入口复用 `rules._context` 与当前共同核验，验证准备摘要、来源/事实/规则派生版本、当前岗位 UUID/版本、每条规则的最终决定。待裁决不得当成最终决定。命中已有快照前仍校验当前上下文，避免缓存跳过证据门。
3. 从不可变 FactPreparation 的全部原始行建立分母；当前岗位、公告及分组条件保留，其他岗位逐项列明排除并保留源行摘要，绝不借用其事实/证据。调查后未知、拒绝、未定位、未处理和不支持分别保留；调查备注、未核验材料等疑点继续列为阻塞原因。
4. 仅以真实 APPROVE 决定构造规则准入，取实际 producer、人工决定 ID、审核员、时间和 EvidenceRef。时间不得猜测；规则审核所保存的生效时间作为有效期起点，终点未确定明确为 null，未来更正由新版本替代，不能冒充永远有效。
5. SQL 保护身份、摘要和不可变历史；读取/返回时由受信适配器重新构造并逐项比对完整计划及上下文，拒绝内容被篡改或已过期的快照。数据库约束不替代这一步；未经此校验的 JSON 不作为可信核心输入。
6. 验证真实 PG 合成薄链路、当前性/重试/并发、终态选择、完整分母、其他岗位隔离、未知与原始备注、重算摘要后的篡改、历史不可变及迁移往返。当前核心输出始终受范围门限制为 UNCERTAIN；本批测试不代替真实人工审核。
