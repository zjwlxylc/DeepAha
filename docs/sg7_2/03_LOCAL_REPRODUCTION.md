# SG7.2 Windows 本地复现与人工验收

版本：**DeepAha 3.7.2-rc1 / SG7.2**。

## 1. 数据目录不要动

继续使用原目录：

`C:\Users\LENOVO\deepaha-data`

不要删除、移动或覆盖。

## 2. 安装方式

1. 停止旧 SG7.1 API / Worker；
2. 将 SG7.2 ZIP 解压到一个新的程序目录；
3. 不覆盖唯一旧源码副本；
4. 双击根目录 `启动机会星图.cmd`；
5. 浏览器打开 `http://127.0.0.1:8000/`。

SG7.2 没有新增数据库迁移，启动器仍会执行既有幂等升级链检查，最终实验层仍为 SG7.1 V2。

## 3. 重点验收

首页：

- 新 Logo 是否正确；
- 首屏是否接近公网原型的成熟产品感；
- “我的机会星图 / 机会总览”是否清楚；
- 找到 → 判断 → 行动 → 品牌收束五段是否自然；
- 手机宽度无横向溢出。

关于我们：

- 打开 `/about`；
- “用 AI 助力青年，用 AI 发现机会”是否符合品牌；
- Logo、蓝橙色、留白是否与首页统一。

旧功能：

- 机会总览；
- 我的机会星图；
- 收藏与行动；
- reviewer/operator 工作台；
- SG7.1 机会实验室。

## 4. 数据安全

本版本不重新调用 WMA，不清空数据库，不修改正式机会 / 审核 / Eligibility / Value / Action 数据。
