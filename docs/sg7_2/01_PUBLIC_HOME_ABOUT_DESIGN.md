# SG7.2 首页与关于我们设计

## 1. 首页信息架构

沿用公网产品原型已经形成的五段叙事：

1. **首屏承诺**：机会星图——让属于你的机会，不再擦肩而过；
2. **找到**：替用户盯机会、读公告附件、整理条件；
3. **判断**：公告怎么写、用户情况是什么、为什么这样判断；
4. **行动**：截止时间、材料、变化、下一步；
5. **品牌收束**：世界是一片机会星空，DeepAha 点亮属于你的那几颗。

这不是另建营销站，而是直接位于真实产品 `/`。

## 2. 双层产品结构

公开层：

- 首页；
- 机会总览；
- 关于我们；
- 官方证据与当前状态。

个人层：

- 登录 / 画像；
- 我的机会星图；
- 资格判断；
- Value / Priority；
- 收藏与行动；
- 消息与反馈。

首页 CTA 直接进入真实 `/app/star` 和 `/app/overview`，不跳转到虚构 demo。

## 3. 品牌视觉

品牌基线：深蓝 + 智能亮蓝 + Aha 橙 + 大面积白/浅蓝留白。

用户上传 Logo 作为统一品牌标识：

- `/product/brand-logo.png`；
- 首页 Header / Footer；
- 登录页；
- 用户端 Header；
- reviewer/operator 工作台共用品牌组件；
- favicon。

## 4. 正式产品与原型的区别

公网原型承担“表达产品愿景”的责任，正式产品还必须承担“不能误导”的责任。因此：

- 保留“值得关注、可能符合、需要确认、官方依据”的结构；
- 不复制演示用 `94%` 匹配度；
- 不宣称成功率；
- 不把 UNCERTAIN 包装成符合；
- 所有真实机会仍进入现有 Catalog / Eligibility / Value 主链。

## 5. 关于我们

`/about` 使用与首页一致的品牌语言，核心内容：

- “用 AI 助力青年，用 AI 发现机会”；
- 世界不缺机会，缺的是发现属于你的机会的能力；
- 从真实源头开始；
- 先回答 Can I，再回答 Should I / Why now；
- AI 提供帮助，不替用户做人生决定；
- `Go Deep. Find Yours. Get the Aha.`。
