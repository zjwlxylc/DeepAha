# SG7.2 Start Here

版本：**DeepAha 3.7.2-rc1 / SG7.2**。

SG7.2 以 **3.7.1-rc1 / SG7.1** 为唯一代码基线。本阶段不改变现实机会生产、整体审核、资格编译、Eligibility、Value/Priority、行动闭环或 Opportunity Lab 业务逻辑，只完成公网产品首页 / 关于我们迁入和品牌层收口。

## 本阶段目标

1. 将当前 `deepaha.com` 已确认的产品化首页叙事迁入真实 SG7.1 产品；
2. 新增正式 `/about` 关于我们页面；
3. 使用用户提供的新 DeepAha Logo 统一替换共用品牌标志；
4. 保留双层产品结构：公开机会层 + 登录后的个人机会星图层；
5. 不复制原型中的伪精确 `94%` 等演示数字；真实产品继续坚持证据、资格与不确定性纪律；
6. 桌面 / 手机均使用同一真实产品路由，不建立第二套静态演示站。

## 不改变

- WMA Direct Call 协议；
- Candidate → 整体审核 → 正式机会链；
- reviewer 整体通过/不通过模式；
- SG6.2 Qualification Compiler；
- SG5 Value/Priority；
- SG7/SG7.1 Twin V2、Gold Oracle、Benchmark；
- 数据库表结构；
- 已有 `deepaha-data`。

## 入口

- `/`：新产品化首页；
- `/about`：关于我们；
- `/app/overview`：机会总览；
- `/app/star`：我的机会星图；
- `/app/actions`：收藏与行动；
- `/review/overview`：审核工作台；
- `/manage/lab`：机会实验室。
