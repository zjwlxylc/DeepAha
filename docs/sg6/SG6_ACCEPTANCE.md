# SG6 Acceptance Gate

必须同时满足：

1. 收藏→准备→申请→等待→完成/放弃的事件历史可回读；
2. 安全截止自动提醒，错误旧截止在更新时取消；
3. 结果反馈可以同步个人行动，但 SG4 Eligibility 不变化；
4. 截止/变化/周摘要可分别关闭；
5. 周摘要一周最多一条；
6. 管理端只能读取脱敏反馈候选，没有直接改规则/事实按钮；
7. 个人导出/删除覆盖 SG6 数据；
8. approved-source 周期 RECHECK 可继续创建任务；
9. SG1–SG5.1 回归全绿；
10. 用户真实 WMA 数据副本不改旧权威表和 object store。
