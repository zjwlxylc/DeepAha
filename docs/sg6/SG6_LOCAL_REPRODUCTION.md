# SG6 Windows 本地复现

1. 停止旧版本；完整备份 `C:\Users\LENOVO\deepaha-data`。
2. 将 3.6.0-rc1 解压到新的程序目录，不覆盖唯一旧源码副本。
3. 保留 `C:\Users\LENOVO\deepaha-data` 原位置，双击 `启动机会星图.cmd`。
4. 首次启动会在既有 `upgrade → upgrade-sg1 → upgrade-sg5-1` 后执行 `upgrade-sg6`，先生成验证过的备份；不会重新调用 WMA。
5. 任选一个有安全未来截止的机会点击收藏：进入“我的行动”，确认产生行动项和后续自动提醒。
6. 状态改为“准备中”，打开“行动时间线”；再记录结果“获得面试/进入下一轮”，确认状态进入“等待”、报名截止提醒停止。
7. 打开“我的关注方向”：分别开关截止提醒、机会变化、每周摘要。
8. 打开“消息与提醒”→“本周机会摘要”。
9. operator 工作台打开 `/manage/feedback`：确认只有脱敏结构化反馈，不显示用户自由文字；没有改规则操作。
10. 来源管理可设置检查周期；只验证产生 RECHECK 任务，不要求为了 SG6 人工验收重新运行 WMA。

人工验收重点：行动链是否自然、提醒是否克制、结果反馈是否足够简单、周摘要是否有持续使用价值。
