本轮没有独立审查员/子代理，不把作者自检写成独立审计。代码以用户实际上传R2为基线，未在共享分支工作或远程推送。

| 范围 | 检查和修正 |
|---|---|
| 权限 | 新接口复用原会话/CSRF，会员不获得角色；原operator继承reviewer保留；原手机管理只读覆盖新页面 |
| 服务与费用 | 预置目录草稿；订单条款快照；明确试用与人工确认；运行和外部调查分开授权；无真实付款调用 |

| 调查执行 | 原创建与prompt阶段检查当前用户/服务期/名额/来源授权；延迟/已发送阶段不承诺零费用；不放宽旧并发 |
| 迁移 | R3新表、完整备份、行数/数据指纹迁移；恢复暂停运行；代际禁止直接用旧worker回退；旧自动安装器阻断 |
