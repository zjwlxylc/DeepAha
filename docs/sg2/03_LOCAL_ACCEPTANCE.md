## C. 语义检查

- [ ] 竞赛卡片/详情不出现“岗位”作为类型名称；
- [ ] 科研 GROUP 只做 scope，发布方仍是研究院；
- [ ] 奖学金陌生字段“综合素质说明”可全文搜索；
- [ ] 无 application_url 的线下政策仍可展示；
- [ ] Root / ancestor / own 三层字段不串 scope；
- [ ] 嵌套 TRACK→PROGRAM_TIER 只发布最具体组别，不重复出赛道卡；
- [ ] 360 / 390 / 430px 无横向溢出。

## D. 停止线

只要出现以下任一情况，SG2 不通过：

- 比赛被显示成岗位；
- 滚动政策出现程序编造的具体截止日；
- 无线上申请链接的正常机会从总览消失；
- 父级共同条件被无依据写成某一个子项自己的确定事实；
- 真实 SG1 的 106 岗位数量或身份发生无解释变化。
