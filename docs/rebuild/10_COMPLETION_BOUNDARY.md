# 当前完成边界与接续入口

## 当前交付是什么
这是**可启动的全栈重建候选版**：完整当前源码和被保留的原项目源码、真实数据库操作、正式样式页面、WMA传输复用、原件/收录/用户闭环与文档。不是已经在你服务器上运行的新版，也不是已完成全部商业化的最终产品。

## 已接通的当前主链
来源人工登记/导入 → 明确Direct WMA任务或已有返回ZIP → 原件保存 → 可恢复投影 → 整体通过/不通过 → 持久总览 → 个人偏好/收藏/行动/反馈 → 站内变化与日期提醒。管理配置、来源启停、任务与记录独立；旧Provider写链不被默认挂载。

## 最先需要的真实验收，不是再一轮大重构
在新目录启动，以已有真实WMA三文件包完成一次收录并回读，再在实际腾讯账号完成一份明确范围调查和一次文件恢复；保留实际Agent发布版本、材料与缺口。随后在隔离PG副本运行同样的决定/并发/撤回/权限测试、原生浏览器验收和备份恢复，最后进行真人使用。

真实材料若出现新结构，优先小范围适配到当前内容投影，**不得恢复逐字段方法认证作为前置**。证据不足只限制相应用途，仍保留可用内容。后续接通旧可信规则引擎时，只能消费当前有效、范围完整的依据；不为了出现肯定判断而删除UNCERTAIN保护。
