# 使用手册

## 一、普通用户（手机浏览为主）
打开站点，可进入机会总览、查看类型、地区和关键词。未授权公开的本地站点需要先登录。机会卡片突出名称、发布机构、当前时间信息与重要备注。进入详情可逐项查看条件、子对象、原句和引用；“继续阅读”保留长内容，不用一个“未知”覆盖全部内容。

“我的星图”根据自己填写的城市、兴趣、目标和技能提供相关性理由。目前不显示匹配百分比，也不把尚未计算资格的机会排除。资格入口显示暂不能完整判断，不意味着你不能报名。

收藏后，在“我的行动”把状态更新为待准备、已申请、等待结果或已完成，补充自己的行动备注。反馈可以记录此前是否知道、是否有用、不行动原因以及面试/录取等结果。系统没有代投简历、代报名或向机构提交个人信息。

能够确定的日期可设置站内提醒或导出全天日历。时间冲突、缺失、滚动受理不会生成假截止倒计时。设置里可关闭通知；所有新变化与截止消息都遵守关闭选择。站内消息不等同于短信、微信或邮件已发送。

个人设置可修改偏好、导出自己的数据、清除自己的画像和行动数据。清除不是销毁官方机会原件或系统审核记录，也不等于自动注销整个账号；停用账号需受控管理命令。

## 二、审核员（电脑浏览器）
进入审核收件箱。打开一份返回，先看整体范围及材料备注，再阅读内容。多个机会可以切换浏览；“通过并收录”始终针对本份完整版本，不需要逐岗位逐字段勾选。

可接受的返回点击“通过并收录”；决定保存后已经生成总览版本，可直接查看。程序暂不会规范化、引用未定位或附件未取得时，重点看备注的实际影响，不再要求你维护算法或批准方法。原始文件与完整报告在材料页可读/下载。

整份结果错误或不可用，点击“不通过”，填写一个整体原因。不能批准的硬问题按钮会禁用并显示具体范围；局部错误只排除受影响条目。

通过后仍看到新问题时，不修改历史结果。准备一个完整更正包重新导入，形成新版本再作一次决定。需要撤回当前机会时，在收录管理中明确撤回并写原因。来源暂停不等于撤回内容。

提示版本变化时刷新当前预览；提交响应丢失可重试，不需要重新逐条审核。当前没有“通过等于本人已核对全部事实”的声明。

## 三、维护人员（电脑浏览器）
**运行与连接：** 分别查看数据库、存储、Worker和WMA状态。连接信息存在不代表远端健康；只有主动检查才记录连接结果。密钥不读回页面；本地保存加密，生产由宿主注入。

**来源：** 登记已确认机构和入口，或导入人工提交的来源资产。查看暂停/活跃来源；暂停只停止新派发，既有总览仍然可读。周期检查设为0不自动运行；设置周期意味着授权未来调用，在安装SDK、启用WMA和Worker运行时执行。来源采集范围要明确，不默认全站所有历史。

**任务：** 新建调查时选择来源、网址、范围与预算。可检查阶段、下载/整理失败和本地取消。恢复仅回收现有结果；没有已知会话/文件时不能冒充恢复成功，也不会自动再次调查。新的调查应另建任务，清楚知道会产生远程调用。

**记录：** 查询导入、连接、启停、任务、决定关联和旧运行概况。旧调查可以通过只读CLI导出，旧批准不能自动成为新批准。没有一键清库、服务器重启、模型选择或用户画像后台。

## 四、首次运行的最低操作
1. 启动脚本创建新数据目录和首个账号，打开工作台。
2. 登记一个已允许的来源，导入一份WMA返回ZIP。
3. 进入收件箱阅读内容和备注，一次通过或不通过；通过后到用户端查看。

真实WMA不是体验上述闭环的前置条件；已保存的真实结果可以直接导入。`examples`内样本只验证软件行为，不能作为真实采集效果、用户价值或官方数据正确性的证据。
