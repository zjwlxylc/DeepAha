# 权限、安全与使用边界

## 已实现的保护
同一账号固定user/reviewer/operator角色，服务端检查，管理权限不隐含收录批准。密码scrypt，随机会话仅存哈希，可到期/撤销；登录失败记录限流，不存在默认密码。浏览器HttpOnly会话、SameSite Cookie、写操作CSRF与Origin限制、TrustedHost及安全响应头。

文件路径、压缩包尺寸/文件数/压缩比有限；原件内容寻址、不可覆盖、回读验哈希。WMA输出按不可信输入处理，JSON重复键、非有限数值与过深结构拒绝安全解析；可保存的返回仍留内部恢复记录。正文和报告不执行脚本/宏；公开字段白名单，结构化内部密钥、注释及审核身份不外泄。

WMA在独立任务边界执行，预算、允许来源与明确scope随任务传入，不向其提供个人画像、数据库访问或审批权限。客户端不能传verified=true升级资格。恢复结果不会自动二次Prompt。SDK无凭据不会领取任务。源头暂停不销毁历史；凭据轮换/Worker故障不撤销原文真实性。

本地Linux连接密文使用受保护密钥，Windows使用DPAPI和目录保护代码；后者未在Windows实机执行。生产密钥只能宿主注入，不由页面读回。日志保存错误代码而非可能包含密钥的任意SDK异常全文。

## 不等于解决所有安全问题
源域名允许列表是业务归属边界，不能单靠域名后缀证明官方身份。Agent仍需要已发布平台的浏览/文件/网络权限控制；应用safe_url只做静态地址检查，不宣称替代网络层DNS重绑定/出口隔离。实际WMA技能不能拥有过大的秘密或公网写权限。

文本精确定位不证明语义、对象作用域或完整覆盖。资料本身仍可能存在错误；一次收录不是审计所有事实。浏览器展示备注不能替代服务端禁止问题值驱动资格和日期动作。

## 上线前必须验证
真实身份接入/口令运维政策、HTTPS和Cookie、CSRF/Host/Origin、访问日志与保留策略、对象存储权限、秘密管理、依赖漏洞检查、服务器出口、备份实际恢复、撤回缓存与消息失效。没有渗透测试、生产密码策略/多因素认证、法律合规审查或高并发压测证据，不作相应认证声明。

当前普通注册默认关闭；公开目录默认关闭；不允许把本地fixture/测试端点暴露公网。文档没有承诺具体合规资质。当前全部测试使用隔离临时数据，不接真人库、不在原55439等端口清表。

## 隐私
用户自行决定画像和行动，内容不发送外部模型；维护员没有用户画像浏览后台。站内通知可关闭，个人导出与清除按本人会话执行。备份含账号哈希与用户数据，必须安全保存。当前无家长监督、自动训练授权、支付凭据、外部身份供应商连接或人格推断。
