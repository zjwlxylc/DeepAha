# SG7 Windows 本地复现与人工验收

版本：**DeepAha 3.7.0-rc1 / SG7 Opportunity Lab**

## 1. 升级前

1. 停止旧版 API / Worker。
2. 保留现有数据目录，不移动、不删除：
   `C:\Users\LENOVO\deepaha-data`
3. 把 SG7 ZIP 解压到一个**新的程序目录**，不要覆盖唯一的 SG6.2 源码副本。
4. 双击根目录 `启动机会星图.cmd`。

启动器会按既有升级链执行，最后新增：

`upgrade-sg7`

SQLite 本地模式会先备份再增加隔离实验表。它不会重新调用 WMA，也不会重写已审核机会、正式事实、资格规则、行动记录或现有用户画像。

第二次启动应直接识别 SG7 schema 已存在，不重复破坏数据。

## 2. 先确认 SG6.2 没有回归

优先检查你刚人工验收过的内容：

- 原采集数据、WMA 返回仍在；
- 原审核通过机会仍在；
- reviewer 仍只做整体通过/不通过；
- 专科画像不会把明确本科/硕士岗位放进 headline；
- `UNCERTAIN + HIGH qualification risk` 仍只进入“待核对/继续探索”；
- 收藏与行动正常；
- reviewer/operator 角色隔离正常。

如果这些出现变化，先不要验收 SG7。

## 3. Operator：机会实验室

使用 owner 或 operator 登录：

`工作台 → 机会实验室`

重点检查：

1. “数字分身”可生成并稳定显示 **100**；
2. 可以把当前正式机会加入实验样本；
3. Lab Case 明确是实验快照，不是审核按钮；
4. 可以为 `机会 × 数字分身` 标注：
   - 资格真值；
   - 推荐真值 FEATURE / EXPLORE / HOLD；
5. 没有 Pair Truth 的项目不应显示虚假的“100%准确”；
6. 独立人工 Gold 必须要求佐证引用；
7. 可以跑 `Catalog Safety`；
8. 可以跑 `Gold Benchmark`；
9. 运行结果应显示是否有 unsafe recommendation；
10. 页面不能出现“实验结果自动改正式资格/规则/审核”的入口。

## 4. 普通用户：机会共创实验

用 user 或 owner 打开：

`我的 → 机会共创实验`

检查：

- 初始状态为未加入；
- 明确点击加入后才成为 ACTIVE；
- 加入后正常查看“我的机会星图”；
- 返回共创实验页可以看到自己的实验摘要；
- 点击退出后变成 WITHDRAWN；
- 退出后收藏、准备、申请等正式功能仍正常。

## 5. 隐私

应明确看到/验证：

- 共创是自愿的；
- 不把完整用户档案交给 WMA 做实验；
- 不因为加入实验改变正式资格结论；
- 不自动把反馈拿去训练外部大模型；
- “导出我的数据”含自己的实验状态/曝光；
- “清除个人记录”会一并清除 SG7 共创记录。

## 6. 推荐的首轮人工实验

本地人工验收通过后，不建议马上开放 1000 人。

第一阶段：

- 先选 10–30 个高质量正式机会；
- 为代表性 Twin 建少量 Pair Truth；
- 重点看 unsafe recommendation、资格错误和明显“推荐不值”的模式；
- 然后再邀请第一批约 30 个真实 Founding Users。

真实用户重点收集：

- 以前是否知道；
- 是否值得关注；
- 是否产生收藏/准备/申请；
- 为什么不行动；
- 后续实际结果。

Synthetic Twin 结果不能替代真人结果。

## 7. 验收通过后

只有你实际看过 SG7 并明确说 **“SG7 人工验收通过”** 后，才把 3.7.0-rc1 作为下一阶段开发基线。
