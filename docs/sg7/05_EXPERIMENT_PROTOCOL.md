# SG7 Opportunity Lab 实验协议 v1

## 阶段 A：工程安全

目标：不让明显不符合/高风险机会进入 headline。

工具：100 Synthetic Twins + Catalog Safety。

通过重点：`unsafe_recommendations=0`。这只是安全门，不是产品价值证明。

## 阶段 B：人工校准

目标：建立少量真正可解释的 `Opportunity × Twin` Pair Truth。

顺序：

1. 选择 10–30 个代表性已发布机会；
2. 独立阅读官方依据；
3. 分别判断资格和推荐；
4. 需要时加入 attestation；
5. 锁定后跑 Gold Benchmark；
6. 记录错误模式，不自动改生产规则。

## 阶段 C：Founding Users

第一批建议约 30 人，目标不是营销，而是打磨。

核心指标：

- Unknown Rate：用户原本不知道；
- Useful/Recognition Rate：用户认为值得关注；
- Action Rate：收藏/准备/申请等真实行动；
- 明确不适合/错误推荐；
- 后续面试/录取/完成等 Outcome。

## 阶段 D：扩大

只有在工程安全 + 真人反馈都健康后，再逐步扩大到 100 / 300 人。

## 不允许的捷径

- 不用数字分身数据替代真人行动率；
- 不用 operator 自己的标签冒充 independent human gold；
- 不因为样本少就输出夸张准确率；
- 不让 Lab 自动修改资格规则；
- 不为了“活跃度”推低价值资讯；
- 不把参与实验变成使用 DeepAha 的强制条件。
