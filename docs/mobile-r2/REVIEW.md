## 安全、数据与兼容性

所有个人端点继续通过当前登录账号隔离；写入保留 CSRF。普通审核员不能进入来源/账号管理，维护员仍继承审核员权限。手机工作台只读是 UI 约束，不是新权限来源。既有角色/证据/整体审核规则未放宽。

LOGO、全部九张海报格式资源、models、eligibility、value、scout、dispatch_policy、worker 与底层对象存储文件字节均与父包一致，见 evidence/mobile-r2/protected-files.json。产品 storage.py 只增加本地锁竞争等待；SHA-256 校验、原件写一次语义、未知远程状态保守恢复和未验证串行约束保留。

画像草稿只在当前页面内存中保存，不写 localStorage / sessionStorage；登出或清除个人数据后清理。邀请码/重置码不持久写入浏览器存储；剪贴板不可用时提供选择文本后手动复制。

R2 无新增表；整个分发包仍含父版本的 experience1 五张扩展表，因此保留累计兼容性锁，不将 schema_change_in_release 误写为 false。启动器不会重置密码或生产配置。
