## 产品原则
用户不是来操作数据库的。核心任务是少费力找到一个真实机会，看清自己是否符合、是否值得，留下一项能执行的准备，再回来接着做。所有界面变化服务这条链；不把未知说成符合，不把收藏说成申请，不以新页面代替原业务接口。

## 已发现的问题与本轮范围
1. 发布入口：固定资源地址导致旧 JS 继续生效。内容指纹目录覆盖完整模块依赖图；HTML 不缓存，兼容路径需重验证；版本可识别。
2. 基础交互：导航返回丢滚动位置；请求失败无原地重试；表单错误只有短暂 toast；快速点击 select 的重复请求；动态表单标签关联不完整。
3. 普通用户手机：紧凑可读导航/消息入口；44px 操作目标、16px 输入、底部安全区；详情主操作和资格入口提前，次要信息折叠但原文完整保留；不重画首页/LOGO。
4. 收藏与准备：收藏幂等且不覆盖已有状态/备注；撤回项目仍可移出个人行动；手机默认列表；准备清单可连续添加、就地编辑、明确删除/冲突提示。
5. 画像与提醒：画像按用途分组、全部可选；保存状态、离开确认、内存草稿恢复；冲突仍需显式确认；提醒开关关闭时给设置入口。摘要统计不截断到50条。
6. 后台各模块：来源/任务/收录筛选切换保留上下文；工作台手机只读不降权；完整表格内滚动且可聚焦；任务指引/研究资料更直观；邀请码/密钥不写入浏览器存储。
7. 交付：新增 API/真实 SQLite 测试、JS 行为测试、手机端到端真实 HTTP 测试（浏览器网络若受限，明确 bridge 边界）、截图人工检查、全产品回归、实际ZIP重解压和文件校验。

## 不改变
正式LOGO、三海报资源；整体审核、证据/资格/排序规则、Scout人工导入、WMA受控并发/密钥边界；既有数据库表。R2 无新增表或破坏性迁移。真人/实体手机/真实WMA/服务器发布不得伪造完成。
