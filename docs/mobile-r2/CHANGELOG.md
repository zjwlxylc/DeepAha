# Mobile R2｜产品级迭代说明

## 一、这轮为什么这样改
机会星图的价值不是展示更多字段，而是让一个普通用户少费力地判断、准备和回到自己的行动。因此本轮优先降低四种成本：在手机上反复滑动；离开详情后重新搜索；重复点击造成状态覆盖；输入一半意外丢失。官网仍是公司门户，保留已验收的正式 LOGO、三张海报及品牌末屏，不再次改成另一套设计。

## 二、逐模块变化
| 模块 | 布局与表达 | 操作与管理 |
|---|---|---|
| 首页、关于 | 保留门户主视觉；手机轮播控件放在图下，避免盖住海报；主要触控区域放大。 | 水平滑动与上下滚动区分；手动操作后暂缓自动切换；保留暂停与减少动画模式。 |
| 机会总览 | 单行搜索、单独筛选面板，类别可横向浏览；卡片统一标题、机构、地区、时间层次。 | 查询、地区、类别、分页保存在 URL，进入详情再返回保留位置；清除筛选有明确入口。 |
| 机会详情 | 将“判断与准备”提前；“我能参加吗”与“值得关注吗”分开；保留原文、备注、时间风险。 | 读取真实收藏状态；重复收藏不覆盖准备/申请进度和备注；已有行动直接进入相应列表。 |
| 我的星图 | 重点推荐与继续探索分层，统一卡片样式；行动摘要保持简洁。 | 统计读取全账户摘要，不受首 50 项列表分页限制；没有推荐时指向可行下一步。 |
| 收藏与行动 | 手机默认列表，电脑保留看板；状态筛选横向排列；周摘要默认收起、展开后有实际机会链接。 | 六状态保留；撤回机会仍可识别并移出个人行动；来源记录与行动历史不因移出被改写。 |
| 个人准备清单 | 手机底部弹层、固定按钮、列表就地编辑。 | 连续添加不反复开窗；新增使用稳定请求键；响应丢失后重试不重复；未完成编辑不被其他操作冲掉；删除有确认。 |
| 画像 | 关注方向、基本资料、更多资格、消息与提醒四组；保存按钮贴近操作区域；保留生日分项输入和清空。 | 仍为版本化 PATCH；离开有确认；当前标签页内存草稿可恢复；冲突显式确认合并，未改字段同步最新值。 |
| 消息提醒 | 手机顶栏有消息入口与真实未读数；消息类型清晰；周摘要可展开。 | 只看未读、当页批量已读；关闭提醒时前往设置，不偷偷替用户开启。 |
| 我的、隐私、账号 | 访客可看清登录的用途；收藏/未读/资料快捷入口；密码可临时显示。 | 错误在表单内持续显示；登录与邀请注册保留来路；退出/切换账号清除前端私有状态；清除资料也清除未保存的内存草稿。 |
| 审核与收录 | 保留用户内容预览、原件、报告分区；硬阻断与不阻断备注继续区分。 | 状态切换、按公告/具体机会切换、详情返回和完成决定保留筛选；整体审核和版本防重不变。 |
| 来源与任务 | 桌面表格统一信息层次，手机来源/任务显示成可读记录卡；后台手机仍只读。 | 远程搜索覆盖全部来源；查询失败不跳过一页；过时响应不替换新结果；选择来源预填 URL，清空选择不删除人工 URL。 |
| 执行策略、来源资产、实验室、账号管理 | 统一输入、对话框、表格阅读和错误反馈；既有真实状态与实验来源标识继续保留。 | 不改变来源批准、WMA 验证门槛、模拟/真人分离、维护员与审核员权限。一次性凭据复制失败时允许手工复制，不写入浏览器存储。 |
| 运行与发布 | 启动输出程序目录与前端指纹；“我的”可识别 R2 版本。 | 完整 ES 模块图用版本目录，静态文件与版本不一致时拒绝以该版本启动。 |

## 三、端到端而不是演示状态
新增幂等收藏、个人行动状态与全账户摘要端点；准备事项、资料、消息全部使用已有真实数据库接口。普通页面不含测试账号切换器或本地模拟业务存储。测试专用数据与桥接代码只在 scripts 与 evidence 下。

## 四、没有改变的边界
资格、推荐价值/优先级、WMA 调度、Scout 包导入、整体审核和原件管理的业务规则保留；正式 LOGO 与 hero 文件做逐字节核对。R2 不增加新表、不改账号口令、不替用户执行报名。对材料未知仍显示待确认，不以页面美化掩盖风险。

本轮是工程候选。上一轮的“人工测试通过”来自用户确认；不能自动延伸成这一轮也已经人工验收。实体手机、Windows 原生、新版正式 HTTPS、真实 PostgreSQL 与 WMA 仍需目标环境核验。

## 回归发现的本地存储问题
两个并行调查保存相同原件时，旧版非阻塞文件锁会立即报忙，造成 NEEDS_RECOVERY。本轮在产品层增加最多2秒的忙锁等待，保留全部原件校验，不重发 WMA、不改变调度策略。回归包含真实文件锁与20轮合成双任务，不能当成供应商并发能力证明。
