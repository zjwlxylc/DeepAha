# Phase 7 Deferred Decisions

These items are deliberately outside the Phase 7 Engineering Gate candidate:

1. **Governed human-participant validation.** Recruit design partners only under a separately
   authorized consent/withdrawal protocol; collect comprehension, cognitive-load and real-action
   evidence without mixing simulation results.
2. **Implementing an improvement.** `EXPLANATION_CLARITY` is synthetic fixture input. Any actual
   explanation, fact, RuleSet or ranking change requires a later versioned candidate, offline/shadow
   comparison and release Gate.
3. **Production identity and reviewer governance.** Select authentication, session lifecycle,
   separation of duties, assignment, escalation, staffing and audit operations.
4. **Privacy lifecycle.** Define retention plus access/export/correction/deletion/withdrawal tied to
   production identity; immutable audit retention must be reconciled explicitly.
5. **External evidence intake.** File upload, arbitrary URLs, new-source collection and evidence
   rights assessment are not accepted by Phase 7.
6. **Phase 8 reminders and channels.** Notification, Outbox, push, mini-program, calendar and
   reminder scheduling remain unimplemented.
7. **Online learning and model use.** No feedback-driven online update, learned ranker, LLM reviewer
   or LLM qualification decision is selected.
8. **Production operations and release.** Hosting, rate limits, monitoring, backup/restore, rollback,
   incident response, deployment and production traffic remain undecided.
9. **Contract stability.** v0.6 remains `IMPLEMENTED`; only a corresponding `QUALIFIED` Release
   Qualification can support a later `STABLE` decision.
10. **Legal/compliance qualification.** Actual operator, participant protocol, features, region and
    scale require current professional review; this package is not legal advice.

These deferrals do not weaken immutable history, authorization, evidence binding or no-online-update
rules. They block Release Qualification and production use, not bounded engineering review.
