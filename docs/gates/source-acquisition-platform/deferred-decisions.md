# P9-A Deferred Decisions and Remaining Issues

These items remain deliberately outside A0-A7:

1. **100-source/14-day qualification.** The Blueprint maintenance target is `NOT_RUN`; five-source
   convergence cannot establish long-run coverage, freshness or maintenance burden.
2. **Production scheduler and operations.** No cron, queue, Redis workflow, distributed scheduler,
   alert routing, operator console, backup/restore or incident process was added.
3. **BrowserFetcher.** No standard browser Fetcher was justified by the selected evidence. If a
   future approved source genuinely requires ordinary rendering, it needs a separate bounded design
   and must still stop on CAPTCHA/login/access control.
4. **Currently inaccessible named routes.** SASAC desktop/mobile remained challenged or unavailable.
   China Mobile public pages depended on signed APIs; no signature reconstruction was attempted.
   Their failure state stays visible and no active Recipe claims success.
5. **S02 lifecycle variants.** Current correction, cancellation and attachment-replacement samples
   were not observed. Future evidence must be real and versioned; none was fabricated for A6.
6. **Attachment host approval.** The Zhejiang detail exposed attachment links, but a later redirect
   reached an unapproved host and was blocked. Adding a host requires a fresh authority/use/policy
   decision, not automatic expansion.
7. **Structured/API/RSS breadth.** The control plane supports declarative JSON/XML discovery, but
   A7 did not claim broad production coverage for every format or source class.
8. **Production data governance.** Retention/deletion, redistribution boundaries, robots/terms
   refresh cadence, security operations and qualified legal review remain Release Qualification
   work.
9. **Contract stability.** The platform contract is `IMPLEMENTED`; it cannot become `STABLE` before
   the corresponding Release Qualification is `QUALIFIED`.
10. **Subsequent slices.** A8 and all work beyond A7 have not started. No push, merge, deployment or
    mass source expansion is authorized by this Gate package.
