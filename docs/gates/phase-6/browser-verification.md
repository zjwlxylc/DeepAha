## 纵向流程结果

1. 从公开机会详情进入“判断我是否适合”，页面保留发布单位、状态、截止时间、最后核验时间、EvidenceRef、官方入口和变化历史。
2. 用键盘依次聚焦跳转链接、品牌、主导航、面包屑和画像入口；所有被检查元素显示实线焦点轮廓，Enter 可进入渐进画像。
3. 画像填写毕业阶段、目标、毕业年份、学生状态、现居地和软偏好，显式跳过可选专业字段，学历留空；提交后保存 Profile v1，缺失信息没有降级成 `INELIGIBLE`。
4. 个人详情返回 `UNCERTAIN`，明确展示缺失学历、满足项/冲突项/缺失项/风险，以及版本和场景时钟；10 个字段可分别回链到同一合成官方 EvidenceRef。
5. 未来 90 天行动台返回 2 张卡片，未超过 3；排序原因可解释，未出现匹配百分比、模型置信度或 Phase 7/8 控件。
6. 保存机会、将状态设为 `PREPARING`、新增“合成报名材料”及计划日期后，摘要、选择框和材料列表一致；重新加载仍保留状态。
7. 点击“记录并打开官方入口”后，先完成后端审计写入，再导航至 `phase5-fixture.example.test` 合成官方域名；该保留域名预期不可解析，回退后个人状态仍保留。
8. 停止本轮 Uvicorn 后打开行动台，页面显示“个人行动台暂时不可用”，没有以旧数据伪装成功；恢复同一 Phase 6 API 后点击“重新加载”，新请求成功并恢复 2 张卡片。

## 可用性与缺陷闭环

- 两个视口均无横向溢出；移动端所有可见按钮、链接、输入和选择控件的实际目标高度均至少为 44px。
- 桌面与移动截图目视检查未见裁切、遮挡、重叠或水印 Logo。
- 首次详情运行发现重复 React key；加入回归测试并改为 `EvidenceRef + field_path` 复合 key，新的干净浏览器会话无该错误或警告。
- 首次行动状态更新后选择框保留旧默认值；加入组件回归测试并按最新 Action snapshot 重置表单，重新加载后摘要与选择框均为 `PREPARING`。
- 首次 API 恢复后错误边界只执行 `reset`，没有发出新请求；加入失败测试并让 Phase 6 三个错误边界执行 `reset + router.refresh`，真实中断/恢复后验证通过。
- 故障注入期间控制台出现预期的连接失败记录；恢复后没有新的重复 key、百分比、敏感会话值或 Phase 7/8 行为。

## 证据限制

本记录证明的是固定合成输入下的工程可操作性、浏览器可用性和恢复路径。它不证明最小画像完成率、真人理解度、认知负担、真实高意图动作、真实机会覆盖、真实资格准确率或生产发布就绪；这些仍属于 Phase 6 Release Qualification 的受治理真人证据工作流。
