# Phase 5 Deferred Decisions

These items are deliberately outside the implemented Phase 5 Engineering Gate.

1. **Real Gold candidate qualification.** Assemble 200 real, permission-clear, verified Gold
   opportunities and run the real-environment completeness/replay qualification.
2. **Clean production brand assets.** Produce approved cropped, transparent and vector logo/icon
   variants from the formal brand baseline; do not reuse the watermarked raster or treat Phase 5
   colors as approved brand tokens.
3. **Phase 6 personal workflow.** Profile collection, eligibility four-state output, personal
   explanation, personalized ranking and action desk require a separate design, contract and Gate.
4. **Production persistence and hosting.** Cloud database/object store, backups, monitoring,
   deployment, CDN/cache policy and production rollback are not selected.
5. **Scale optimization.** The finite in-memory projection is sufficient for the planned 200-item
   candidate set. Database search indexes, full-text search and larger-feed optimization require
   measured need and must not become an unlimited announcement stream.
6. **Offline PWA and notifications.** The manifest provides a minimal installable shell only; no
   service worker, offline data sync, push notification or reminder behavior is implemented.
7. **Contract stability.** The Phase 5 Public API remains `IMPLEMENTED`. It can become `STABLE` only
   after its Release Qualification is `QUALIFIED`.
8. **Legal/compliance qualification.** Actual public operation requires current legal review based
   on operator, features, region, scale, data use and AI-content marking obligations.

None of these deferrals blocks normal engineering work after the Phase 5 Engineering Gate closes,
but all applicable release items block production qualification.
