# DeepAha V2 · 前端交付

依据：`reference/2026-09-13-wma-overall-review-and-overview-replan.md`，2026-09-14 修订。

## 入口

- `DeepAha_V2_User.html`：手机用户界面，默认 `/app/home`。
- `DeepAha_V2_Review.html`：电脑工作台，默认 `/review`。
- 工作台右上角“访问站点”在同一文件中打开用户页面，可查看刚收录的内容。
- 两份 HTML 均自包含，无 CDN、字体下载和构建依赖。通过 `python build.py` 从 `src` 重建。

## 实现约束

本包是离线界面与交互参考，不是已上线业务程序。`fixtures.js` 中全部机会、机构、原件、连接状态、运行时间和账号均为虚构资料，不能写入正式库。HTML 不执行真实调查、申请、支付、网络检测或通知投递。

`model.js` 仅演练前端状态。浏览器内权限、localStorage、来源域名比较、版本比较和定时回调，不是生产认证、事务、并发锁、域名授权或任务恢复实现。正式业务必须使用规划中的服务端角色检查、持久预览、幂等决定、事务/恢复、只读公开投影与领域使用限制。客户端不能提交已通过字段清单。

连接页面体现“部署托管秘密”的上线形态，只有配置状态及显式检查，没有密钥明文、模型选择器或生产密钥编辑框。界面中的健康读数来自固定样本，检查连接按钮用于演练超时；接入时必须替换为真实、分组件检测结果与超时状态，未知不能报健康。不得将样本读数或本地回调当作已验证 WMA/数据库能力。

正常与带备注内容一次整体收录；不逐字段批准、不审批方法、不补资格规则、不增加第二次发布。维护权限与审核权限独立，暂停来源仅停止新派发。任务恢复区分本地整理与原会话附件访问，不重跑已完成的调查。原始材料不可改写，已证实错误值不出现在公开投影中。

保留公共内容的真实备注、材料缺口和时间冲突；不得为清理界面文案删除这些业务信息。仅去除设计意图、演练、开发说明等非业务文案。原件弹层中未定位的内容不会显示为原文引用；未知资格不被展示成“不符合”。

用户端独立入口、移动优先；工作台为电脑布局。不要重新加入“用户端/审核端”原型工具条、屏宽切换器、演练开关或说明浮层。源码中的注释和本文件不进入页面。

实施仍按原规划 P1–P5，先接通真实一次收录闭环，再接四个管理出口。不借前端改版扩建管理平台，不删除共享服务与历史迁移，不复活旧 Provider 公告理解写入口。本包未包含仓库修改、服务部署、数据库迁移、真实 WMA 调用或真人业务验收。

## 样本范围

招聘、实习、竞赛、政策与通用类型；正常、带备注、来源错配、读取中断、更正、撤回；重复标签、最低服务期、或条件、作品知识产权、滚动受理、线下办理、每年最高金额及陌生字段。

列表每页 6（历史 7）项；岗位每页 6 项；分区条目每页 12 项。交互参考采用本地数组，生产必须接服务端有界分页/读版本，不一次加载完整千级返回。功能外的支付、来源导入编辑器、账号 CRUD、服务重启与备份控制台未扩建。

## 存储

浏览器键：`deepaha-ui-v2-20260914`。原始附件、密钥、真实账号和私人信息不应存入该状态。不同 file:// 文件在不同浏览器中可能隔离存储；跨端联动应在工作台内使用“访问站点”，或在同源 HTTP 下运行。生产版不使用这里的 localStorage 作为权威存储。
