# SG5 本地体验建议

不需要导入新的专用 SG5 数据包。SG5 可以直接使用你已经收录的 SG1–SG4 Target。

建议在独立测试数据目录中组合 `examples/` 下已有的竞赛、政策、科研等虚构包；或者直接在你的真实数据库副本上测试以下画像：

1. **政策探索**：城市=宁波，兴趣=政策，不显式选择类型；观察系统能否优先拉起真正政策 Opportunity。
2. **显式政策**：机会类型=人才政策，城市=宁波；观察候选是否收敛到政策。
3. **AI 竞赛**：机会类型=竞赛，兴趣=AI，目标=积累项目经历；观察赛道排序。
4. **关闭个性化**：取消“启用个性化机会排序”；星图停止计算，但机会总览仍可浏览。

这些画像只是验收建议，不会自动写入数据库。
