## 已知范围约束

- 源码包不是 Windows EXE。需要 Python 3.11+ 和 Tk；核心与演练不需要安装第三方依赖。
- 所有默认入口都不会连接生产库。SQLite/PostgreSQL 参考仓储仅能用于 DEMO/TEST/STAGING，服务拒绝把参考后端设成 PRODUCTION。
- `scout_import_*` 是可执行研究暂存参考，不声称等于主项目 Source、Brief 或事实表。不得为图省事创建第二套正式来源权威。
- 窗口第一版只做候选入库，正式启用使用 DeepAha 现有审核入口。服务和 CLI 的独立批准选项只有宿主权限与事务回调接通后可用。
- 对源站官方身份、研究内容和证据语义，导入器不做 AI 判定。文件与引用校验通过不等于研究事实正确。
- 回执回传 Library 是可选反馈；本程序不自动上传回执。非生产回执已明确标记，不得用于更新 Scout 的正式系统状态。
- Handoff 规范仍为 v2.2。内部可执行字段细化与文件依赖扩展在 `docs/CONTRACT.md` 独立说明，不冒充原提示词已写死的协议。
