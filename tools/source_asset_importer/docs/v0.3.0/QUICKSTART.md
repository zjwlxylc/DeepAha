# 日常使用：只需要知道这几件事

## 文件选哪个？
有完整WB-scout.zip就选整个ZIP，不用先解压。GPT多轮可以选所有Handoff；同时带上State/Review，能保留更完整的参考资料。不要只选State来代替Handoff。混合批次保留“按批次格式识别”；不要把WB强行选成GPT。

## “37个来源”为什么不是92个？
92是历史观察次数；同一候选有更新，合在一张卡片中查看。卡片里的“版本记录”仍保留原件和全部观察。网址相同只提示关系，跨研究者不同身份不会自动消失。

## 我到底要点什么？
先看“需先补充”和“有疑点”。核对依据后：值得留作研究候选就“建议接收为候选”；入口/文件还不清楚就“暂缓”；确实不适合当前用途才“不采用”。三种决定都不会删除原件，也不会批准采集。保存前填写原因；想改就撤销或保存新的意见，旧意见仍能追溯。

## 颜色和提示什么意思？
“结构检查未发现阻断”不等于官方真实性已确认。“暂缓”不是来源永久失效。“文件哈希一致”只证明字节符合记录，不证明内容是正确事实。遇到登录墙、多个入口、政策旧版本时保留问题，不为得到绿灯填一个猜测值。

## 导出后去哪里？
浏览器下载一份ZIP，同时保存在本机exports目录。查看ResearchHandoff.json的readiness、counts和Decisions.json。DeepAha现阶段需要R2暂存接入改造，不能把该ZIP直接当旧单批可执行文件提交。研究资料已整理与系统已经接收完全不同。

## 下次还要重新来吗？
不用：左侧“最近的本地审核”恢复会话。新文件建议新建审核，不覆盖旧原件。导出的交接ZIP不是一个新的Scout输入；跨电脑请解压originals后选择原始JSON/ZIP，原意见在Decisions.json保留作参考，不会自动算新操作者批准。

## 资料库读取失败怎么办？
界面会显示Codex/权限/文件证据的问题。不要把Token、Cookie或数据库密码粘进文件。账号没有Library工具时，继续用你原来的手动下载和选择文件方式。勾“联网下载”不能修复缺失的资料库权限。

## 浏览器没打开怎么办？
启动终端会打印含本机会话令牌的127.0.0.1地址，复制到同一台电脑浏览器；不要发给别人。若企业策略禁止本机地址，请由管理员明确放行，不要修改浏览器策略绕过。正常关闭：在启动终端按Ctrl+C；已保存意见仍在。

## 升级和回滚
新版本解压新目录；原v0.2保留。新版审核放在research_workbench，与旧单批演练和回执分离。要回滚，只退出新版、运行旧程序；旧程序不能读取新版研究契约，不要用它覆盖新版数据库。

本轮交付的CSV/JSON辅助意见来自ChatGPT审核，不是你本人已经点过的批准。打开新工作台默认仍由你决定；系统真假反馈由DeepAha真实记录验证。
