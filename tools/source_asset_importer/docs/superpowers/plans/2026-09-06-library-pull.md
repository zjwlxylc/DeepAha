# Codex CLI 资料库取文件增量实现计划

目标：在 v0.1.0 前增加“程序 → Codex CLI → 指定个人资料库 → 原件下载 → 原导入流程”，而非让用户打开 Codex 来运行导入器。

用户已经确认实施，并明确要求本轮不运行测试。本计划仅涉及源码和文档，不修改主仓、不配置真实账号、不调用真实 Codex、不连接数据库。

## 实现范围
1. 新增受限的非交互 Codex 进程调用器：独立工作目录、输出契约、超时/取消、环境凭据过滤。
2. 新增 list/fetch 两阶段资料库适配：只读指定文件夹；按实际工具返回的文件 ID/版本获取原件；拒绝摘要拼接和虚构文件；本地检查字节与依赖后交给既有 Package。
3. 新增中文“从资料库获取”窗口：读取列表、选择批次、取回载入；原有确认入库不改变；手动选文件仅保留为独立入口，不作为自动获取失败的隐式替代。
4. 新增 library-list/library-fetch 命令并更新使用说明、版本和接续文档。
5. 打包 v0.2.0，记录 NOT_RUN；旧 evidence 只属于 v0.1.0。不执行自动化测试、GUI、实际 CLI、网络导入或生产操作。

## 边界
代码能启动 Codex，不代表账号已有 ChatGPT Library 导出权限。只使用当前 CLI 实际提供、已授权的文件工具；没有工具/授权时清晰返回失败，不安装插件、不抓取 Cookie、不猜私有 API、不扩张来源探索。

只保留用户发起的取文件动作；不在下载后自动提交，不上传回执，不启用 WMA。
