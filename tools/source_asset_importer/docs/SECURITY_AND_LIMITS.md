# 安全边界与本轮限制

## 已实现的边界

导入核心仍将输入视为资料，不做模型判断、网页抓取、宏执行或任意 SQL 拼接。v0.2.0 的新增前置入口会按用户点击调用 Codex 读取/导出指定资料库文件；不是定时同步，不自动写资料库。详见 LIBRARY_PULL.md。

客户端默认 TLS 验证；拒绝 URL 内凭据和重定向；仅显式本机演练允许 HTTP，PRODUCTION 不能明文。授权值不接受 CLI 明文参数，不保存到 settings、回执或预览记录；本机输入仅本次会话持有，环境变量可另行提供。参考服务只保留 token 的 SHA-256 映射，不写入日志。

服务端明确身份与 producer 命名空间，预览/提交/查询/正式批准分别校验权限。API 不存在发布或启动 WMA 的入口。

预览是只读事务；提交需要未过期、未被修改且绑定具体输入与环境的确认。数据库修改发生在事务内。SQLite 写事务使用 BEGIN IMMEDIATE；PostgreSQL 参考适配锁元数据行序列化小批次导入。回执与资产一起持久化。

小型参考仓储的全局代数意味着无关批次也可能使旧预览失效，用户需重新预览。这是简单而保守的策略，不是高吞吐分布式平台。接主仓后可在保证不退化的前提下改成实际行版本与锁。

本地回执通过同目录临时文件加不可覆盖链接发布，再回读检查；重送相同回执复用文件。目录不支持硬链接时明确失败，请使用本机常规文件系统。服务端已入库但本机保存失败，提示查询/恢复回执而非说入库失败。

## 不应误解的保证

格式、哈希和引用验证不证明官方身份或内容正确。入口形态/规则等长文本仍是候选研究资料。凭据字段过滤不是完备的敏感信息识别系统。

操作者机器、OS账号、客户端配置、企业代理和宿主权限本身仍须可信；本工具不防御已控制用户电脑的恶意软件。演练目录有本地签名文件，应保留在个人工作目录，不共享或上传。

回执是通过受认证的服务器连接取得的结果记录，不是可对任意第三方离线验证的数字签名公证。需要更强签名机制应复用项目实际审计设施，不在本轮假装已具备。

## v0.2.0 特别边界

本轮未运行测试或实际 Codex。新的调用器能否使用用户个人资料库，依赖本机 CLI 已有工具与权限；权限未被本包创建。Codex 继承的配置和工具不受本进程环境变量过滤完全隔离，应使用必要的只读资料库权限。

## 尚未在真实环境验证

- 用户 Windows 原生双击、Python安装、字体/DPI和企业网络代理。
- 用户实际 DeepAha 的模型、认证、已有数据、正式 Source ID 与审批服务。
- PostgreSQL 实例、迁移权限、与主仓其他业务事务的并发。
- 生产对象存储策略、备份、审计/报警、部署TLS与密钥轮换。
- WMA 从导入并批准的来源真正创建采集任务。
- ChatGPT 定时任务资料库自动归档与跨轮继承（不属于本地导入器）。

本包没有访问上述服务，没有对生产库写入，也没有把本地自检当成独立生产验收。
