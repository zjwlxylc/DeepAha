# Changelog

## v0.3.1 — 2026-09-13

- 在启动资料库任务前检查本机Codex程序、参数、登录及Apps开关；不把CLI正常等同资料库已授权。
- 弹窗内提供阶段、等待秒数、取消、脱敏诊断下载；限制目录60秒和整批10分钟，拒绝重复点击。
- 无工具、参数不支持、未登录、网络/额度错误明确停止；不自动安装插件、改授权或绕过沙盒。
- 支持旧CLI缺少可选ephemeral参数的显式检测；必要沙盒和结构化输出参数缺失仍拒绝执行。
- 完成审核后显示“本次来源都已处理”，可查看已处理项并导出；r58显示为58次操作。
- 新导出分别记录analyzed_at、last_reviewed_at、exported_at；重复导出复用原包，旧包不改写。
- 保留手工文件/文件夹输入、GPT/WB归组、旧单批内核和生产边界。
- 真实用户账号的个人资料库字节取回尚未验证；详见本版VALIDATION。

## v0.3.0 — 2026-09-13
- 在v0.2.0上增量增加离线研究包适配、候选历史归并、跨批引用与附件声明核对。
- 新的本地浏览器工作台：多选/拖拽/文件夹、过滤、详情、可撤销审核、带原件交接与未认证系统反馈查看。
- 保留旧严格Package/事务/认证/服务端/单批界面；不放宽旧契约来强行接入真实Handoff。
- 保留程序主动调用Codex取回原件，新增研究JSON/ZIP协议；实连权限仍需用户环境核验。
- 新增受控State基线工具：验证父链，旧缺口永久留档，不伪造全历史完整性。
- 本批真实回放：GPT30+WB18，164条候选观察/89身份组，33附件；具体问题与测试见版本文档。
- 当前限制：新交接需主系统R2适配；Windows、实时Codex/Library、生产回执认证未验证；浏览器HTTP导航被环境策略阻断，离线DOM验证单列。
